Gemini MCP Server

A Cloud Run Gemini Based MCP Server

Python based server-client MCP server using Google APIs and requests. Agent takes a book name and queries google books API, then uses that information to suggest like books. Agent then takes location input and shows nearby bookstores. Libraries: fastmcp, langchain, requests, langgraph, langchain-mcp-adapters, langchain_google_genai
